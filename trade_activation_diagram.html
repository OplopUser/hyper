Trade Activation Flow

Hyper Bot — from loop iteration to order execution

Main Loop Tick
Bot wakes every 60s and iterates over each symbol in SYMBOLS
Fetch Mid Price
Get current market mid-price from exchange
Skip iteration if unavailable
Manage Existing Positions
Check if any open position hit stop-loss or take-profit → close if triggered
Risk Pre-checks
Can Open Trade?
• Trading not halted (drawdown < 10%)
• Account equity > 0
• Open positions < max 3
• No existing position for this symbol
Any check fails → skip symbol
Data Fetching
Fetch Candles
Primary: 15m × 200 candles
HTF: 4h × 100 candles (for trend filter)
Skip if primary candles empty
Signal Generation
Compute Indicators
EMA Fast 9 • EMA Slow 21 • RSI 14 • ATR 14
Requires ≥ 50 candles and ≥ 2 valid indicator rows
EMA Crossover Detected?
LONG: prev_fast ≤ prev_slow AND curr_fast > curr_slow
SHORT: prev_fast ≥ prev_slow AND curr_fast < curr_slow
No crossover → Signal = NONE, stop
Signal Filters (all must pass)
Filter 1: RSI Range
RSI must be between 30 and 70 (neutral zone)
Oversold / overbought → blocked
Filter 2: HTF Trend Alignment
4h EMA(21) determines trend
LONG only if trend = bullish • SHORT only if trend = bearish
Counter-trend → blocked
Filter 3: Volatility Regime
ATR percentile over last 100 candles
• Low (< 20th %ile): ranging → block
• High (> 95th %ile): chaos → block
• Normal: allow
Extreme volatility → blocked
Trade Setup
Compute SL / TP
LONG: SL = entry − ATR × 1.5  |  TP = entry + ATR × 3.0
SHORT: SL = entry + ATR × 1.5  |  TP = entry − ATR × 3.0
Validate SL / TP
LONG: SL < entry < TP  •  SHORT: TP < entry < SL
Invalid levels → skip
Position Sizing
Compute Position Size
size = (equity × 2% risk × 1x leverage) / |entry − SL|
Rounded to exchange decimals, notional ≥ $10 min order
Below minimum → skip
Execution
Place Market Order (IOC)
Submit aggressive limit order via Hyperliquid SDK
SDK failure → log & continue
Record Position
Create PositionRecord in RiskManager — tracks SL/TP for subsequent iterations
